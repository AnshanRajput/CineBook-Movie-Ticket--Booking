# CineBook - Movie Ticket Booking System

CineBook is a Python-based command-line Movie Ticket Booking System. It allows users to view movies, check seat availability, book tickets, cancel bookings, and search for booking details.

## Features

- Display available movies
- View movie language and ticket price
- Check available and booked seats
- Book movie tickets
- Generate a unique booking ID
- View all bookings
- Search for a booking using booking ID
- Cancel existing bookings
- Calculate ticket amount
- Simple and user-friendly command-line interface
- Input validation for user choices and booking details

## Technologies Used

- Python 3
- Python Standard Library
- Command-Line Interface (CLI)

## Requirements

- Python 3.x
- No external Python libraries are required
